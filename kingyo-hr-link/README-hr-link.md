# 金魚シフト：人事ツール連携 API（api/hr-link.js）

このフォルダの `api/hr-link.js` を、金魚シフトのリポジトリの `api` フォルダに追加してください（既存ファイルの変更はありません）。

- 読み取り専用。人事ツールのサーバーだけが、共有シークレット `HR_LINK_SECRET` の署名付きで呼び出します。
- 返すのは設定値と集計値のみ（氏名・希望・メモ・予定は返しません）。
- Vercelの環境変数 `HR_LINK_SECRET` を追加して Redeploy してください（人事ツール側と同じ値）。
- 既存の `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` をそのまま使います。

注意：Vercel Hobby プランは1プロジェクトあたりのサーバー関数の数に上限があります。追加後にデプロイが失敗した場合は、エラー文を確認してください。
